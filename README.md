# Phishing ML Project

An end-to-end machine learning application for detecting potentially
phishing URLs using URL-level analysis, character-level TF-IDF features,
and a calibrated Linear SVM classifier.

The project combines machine learning research, model evaluation,
security-oriented URL analysis, interpretability, and a deployable
web application into one system.

---

## Overview

Phishing attacks commonly use deceptive URLs to imitate legitimate
services and trick users into revealing credentials, payment information,
or other sensitive data.

This project investigates whether phishing URLs can be identified using
the URL itself, without needing to visit or scrape the target webpage.

The core pipeline is:

Raw URL
   ↓
Input normalization
   ↓
Character-level TF-IDF
   ↓
Linear SVM
   ↓
Probability calibration
   ↓
Phishing probability
   ↓
Risk score
   ↓
Human-readable analysis
